# MiniClaw

MiniClaw 是一款面向家庭长辈的语音陪伴助手。它以自然对话为入口，支持不同家庭角色、家庭提醒和受控的长期记忆；家人可通过独立页面管理角色设置、共享信息、授权和提醒情况。

## 项目背景与目标人群

长辈使用数字产品时，复杂的操作流程会成为障碍；家庭也需要一种可持续管理提醒、同时尊重个人隐私的陪伴方式。MiniClaw 将语音交互作为主要入口，并把对话能力与提醒执行、记忆存储和家庭管理结合起来。

主要使用者是需要语音陪伴和日常事项提醒的长辈。家庭成员可协助配置角色、查看经授权的家庭共享内容、管理提醒与访问权限。

## 功能概览

- **语音与文字对话**：浏览器录音后上传音频，服务端转换并调用兼容的语音识别、对话模型和语音合成接口；文字对话以流式方式返回。原始音频及转换后的音频不会持久化保存。
- **家庭角色**：提供女儿、孙女两种角色配置。角色设置按家庭保存，可切换并在下一轮对话生效；切换时会播放角色自我介绍。
- **提醒管理**：支持创建、查询、完成、改期、暂停、继续和取消提醒，支持时区与重复规则。提醒由独立调度进程触发，并有站内提醒、Web Push、重试和升级通知流程。
- **长期记忆**：将角色私有记忆与经授权的家庭共享记忆分开保存。仅在用户明确要求记住时保存支持的偏好类内容；用户可以查看来源、删除记忆或撤回共享授权。
- **家庭管理**：家人可管理角色配置和共享事实，查看提醒、授权的共享记忆、未确认提醒、设备与通知状态、使用情况及变更记录，并执行数据导出或删除。
- **账户与访问控制**：提供长辈配对、家庭一次性验证码登录、短期访问令牌及刷新机制。受保护接口根据令牌身份进行家庭和成员范围的数据查询。
- **渐进式 Web 应用**：提供 PWA 安装能力、离线静态提示页和设备端语音提示。
- **可观测性与评估材料**：记录请求链路与阶段耗时，提供开发调试页面、家庭使用统计接口，以及角色、安全、提醒和授权场景的离线评估用例。

## 关键设计

### 确认后执行提醒

涉及写入的提醒操作不会由模型直接修改业务数据。系统先校验事项、日期时间、时区和重复规则等必要信息，再创建待确认操作并向长辈复述，由用户通过按钮确认后执行。确认有时效，超时按拒绝处理；部分高风险操作需要再次确认。确认记录和审计结果持久化保存。

提醒记录使用幂等键避免重复创建，并通过版本号校验并发修改。调度器使用数据库锁领取到期任务，单次触发记录和通知投递记录分开保存，以便处理重试和重复投递。

### 家庭记忆与上下文控制

业务提醒单独存储，不混入一般对话记忆。长期记忆按角色私有或家庭共享范围管理；家庭共享内容需要授权，查询时在数据层按家庭、成员、角色、范围和状态筛选。删除或过期的记忆不会继续注入对话。

对话上下文通过保留近期轮次、汇总较早内容和配置 token 预算控制长度。完整业务消息保存在数据库中；LangGraph checkpoint 单独使用 PostgreSQL schema，并可按保留期限清理。

### 工具与权限边界

模型可调用的工具由后端注册表集中管理。工具参数经 JSON Schema 校验，执行设置超时，读取类工具与写入类工具采用不同权限路径。只读工具用于查询当前时间、提醒和经授权的共享事实；写入提醒仍需走明确的确认流程。API 从认证身份取得家庭和成员信息，不依赖浏览器提交的身份字段。

## 技术栈

- **前端**：Next.js 15、React 19、TypeScript；PWA 与浏览器端录音、语音播放。
- **后端**：Python、FastAPI、SQLAlchemy、Pydantic Settings、Uvicorn。
- **Agent 与模型接口**：LangGraph、LangGraph PostgreSQL Checkpoint、OpenAI Python SDK 的兼容接口；语音识别与语音合成通过 OpenAI 兼容服务接入。
- **数据与迁移**：PostgreSQL、psycopg、Alembic；使用 tiktoken 估算上下文 token。
- **定时与通知**：独立 Python 调度进程、Web Push（pywebpush）、时区与重复规则处理。
- **部署**：Docker Compose、Caddy、ffmpeg；生产配置与运维脚本位于 `ops/`。

## 本地启动

在 `MiniClaw` 项目目录中准备环境文件并配置模型服务参数：

```bash
cp .env.example .env
docker compose up --build
```

启动后访问 `http://localhost:3000`。API 健康检查地址为 `http://localhost:8000/health`。语音功能需要配置可用的 OpenAI 兼容服务及 API 密钥，并在浏览器中允许麦克风访问。更多环境变量见 `.env.example` 与 `api/app/config.py`。

## 评估与项目状态

`evals/` 包含提醒抽取、角色一致性、提示注入和授权场景的离线用例。评估脚本为 `evals/run_eval.py`，可通过以下命令运行：

```bash
python evals/run_eval.py --predictions evals/predictions.json
```
